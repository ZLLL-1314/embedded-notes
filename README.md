# 嵌入式学习笔记（embedded-notes）

物联网工程专业 → 嵌入式软件方向。自 2026 年 10 月起记录 C 语言、STM32、FreeRTOS、ESP32 与物联网协议的学习过程与代码。

**目标**：2027 年寒假前拿到成都地区嵌入式 / 物联网方向实习 offer
**起点**：C 语言基础薄弱，从指针、结构体、位运算重新打地基
